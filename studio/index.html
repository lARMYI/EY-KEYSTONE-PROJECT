Client Build Studio

Build anything for a client — framed, grounded, certified, published.

A method, expressed as an application. It organizes the work into sections, areas and artifacts; holds every artifact to criteria written before the draft existed; drafts with agentic AI that never leaves you with nothing; and refuses to publish anything it has not certified. Everything on this page is rendered from a single data spine — including the part that lets the app add to itself.

Where an engagement gets to

Readiness is derived, never asserted. It rolls up from what is actually drafted and certified in the current engagement, so the ladder moves only when the work does.

The method

Eight sections. Each holds areas; each area answers named questions, owns criteria, and produces artifacts. Every area links to the place in the worked example where that move is visible in something that shipped.

How criteria work

Three kinds, and one rule the Gate enforces mechanically.

The Gate rule

An artifact certifies only when every binary criterion passes, zero claims are Unsourced, and every assigned persona review is resolved. High-severity criteria cannot be waived. Certification mints a passport carrying the criteria results, the claim statuses and an evidence hash.

The six lanes

Sections, areas and criteria are media-neutral. A lane supplies three things and only three: what good means in that medium, the criteria that medium imposes, and an adapter that assembles certified artifacts into something openable.

The red team

Six readers, each a lens with a named failure it hunts for. Personas are data — adding one makes it assignable to review criteria everywhere at once.

How this grows

Three write paths into the spine, all human-accepted, none automatic. Accepted nodes land in a local overlay — the shipped spine file is never written by the browser.

◇

Node proposal

The agent reads the diagnosis and proposes a schema-conforming area or artifact. You accept, edit, or reject it. Accepting renders it immediately.

◈

Draft generation

Three tiers: a deterministic composer that always works, a live agent when the host provides one, and a copy-out prompt pack for anywhere else.

◆

Pattern promotion

An artifact that worked becomes a library pattern, criteria attached, client material stripped. This is what makes the playbook compound.

Spine integrity

The validator runs at load on every page. A malformed spine is reported here rather than failing silently — duplicate ids, unknown criterion kinds, dependency cycles, criteria naming tests that were never registered, and areas with nothing that can fail.
