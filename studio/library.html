Library

Everything the method knows how to build.

Six lanes, their artifact patterns, every criterion in the catalog, and the six readers the red team runs. Adding to any of these is how the playbook grows — a new persona becomes assignable everywhere at once; a new pattern becomes draftable immediately.

Lanes

A lane supplies what good means in that medium, the criteria the medium imposes, and a publish adapter. It never changes the sections, areas or criteria above it — that is the test of whether something is really a lane.

Patterns

Each pattern is an ordered list of parts with a hint and a composer template. The deterministic composer fills them from the commission; the live agent drafts on top of that baseline using the same headings.

Criteria catalog

Written before any draft exists. A criterion that can never fail is not testing anything — the diagnosis flags that too.
